# Personal Website

## Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- npm

## Local Development

Install dependencies:

```sh
npm install
```

Start the dev server:

```sh
npm run dev
```

The site will be available at `http://localhost:5173`.

## Build

```sh
npm run build
```

Preview the production build:

```sh
npm run preview
```
